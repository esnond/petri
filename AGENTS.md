# agent manifest, read before any work

this repository is maintained with a private skill pack (thirteen
skills, developed by the author, kept outside the public tree). the
constitution in one paragraph:

behavior emerges only from sensory currents, synaptic weights,
intrinsic dynamics, modulators, mechanics, proprioception and noise.
no behavioral rules, no state machines, no gradient vectors. a broken
phenotype is fixed by coupling or constants, never by adding a rule.
same seed plus same flags plus same connectome equals bitwise
identical output; verify with cmp before committing sim loop changes.
c99, libc and libm only, warnings are errors. csv headers are frozen
in docs/schemas.md. every published number is a csv plus a seed.
every biological claim cites a source or is marked assumption.
limitations only grow. new ideas go to docs/what_remains.md.

registry and defects: docs/DEFECTS.md. lab notebook and validation
channels: docs/NOTEBOOK.md. datasets: docs/DATASETS.md. process:
docs/PROCESS.md.
